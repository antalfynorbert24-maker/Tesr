# RideCircle Android APK

This repository contains a self-contained on-device **demo** of RideCircle with regional feed, groups, discovery, chat simulation, events, XP and achievements. It is **not** the full earlier source project, and it does not include live GPS, maps, backend, actual users, or prize fulfillment.

Go to **Actions → Build RideCircle APK** and open the latest run. After a successful build, download **RideCircle-Android-APK** under Artifacts. Extract the APK and install it on Android. This preview build uses development/demo signing; do not distribute as a production release.
